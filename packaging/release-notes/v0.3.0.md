青截 v0.3.0 · Windows 10/11 64 位

### 下载使用

- **QingJie-v0.3.0-Windows-x64.exe**：单文件版，下载后双击即可使用，无需 Python。启动时需要解包运行库，建议保存在固定目录。
- **QingJie-v0.3.0-Windows-x64-portable.zip**：便携版，完整解压后双击 QingJie.exe，需保留 _internal 文件夹。适合日常使用，避免每次启动时解包运行库。
- OCR 模型已包含在两个版本中，识别在本机完成，不上传图片。

### 功能

- 拖动框选截图，复制或保存 PNG。
- 本地中英文 OCR，支持结果编辑、复制与实际耗时显示。
- 自定义全局快捷键：默认 Ctrl+Alt+A 截图，Ctrl+Alt+O 截图识字。
- 后台预热和标准/精细识别模式。
- 设置中可开启/关闭 Windows 登录启动，启动后常驻托盘。

### 更新与验证

更新前从托盘退出旧版。若移动程序目录，请取消再重新勾选“开机启动”，以更新启动路径。

EXE 的文件版本为 0.3.0.0，产品版本为 0.3.0。两个构建均通过实际 EXE 的 OCR、窗口启动、精细模式及 Windows 启动项注册/删除检查。附有验证报告和 SHA256 校验文件。

此程序尚未进行代码签名。当前仓库为私有仓库，下载需要有仓库访问权限。
