青截 · Windows 10/11 64 位便携版

1. 将 ZIP 完整解压到普通文件夹（不要在压缩包内直接运行）。
2. 双击 QingJie.exe，无需安装 Python，无需配置 API Key。
3. 默认 Ctrl+Alt+A 截图，Ctrl+Alt+O 框选识字。
4. 可在主窗口修改快捷键，点击“保存快捷键”。
5. 框选后 Enter 复制；Esc 或右键取消；工具栏可保存 PNG 或 OCR。
6. 点击窗口关闭按钮后常驻系统托盘；右键托盘图标选择“退出”完全结束。

OCR 模型已经包含在包中，文字识别在本机完成，不上传截图。
请保留 _internal 文件夹；启动后会在后台准备 OCR，待界面提示“OCR 已就绪”后识别更快。
默认使用标准模式；小字或密集文本可勾选“精细识别”，该模式耗时较长。
识别结果下方会显示从点击到完成的实际耗时。
多屏幕时在目标屏幕上放置鼠标再按快捷键；暂不支持跨屏框选。
快捷键与其他软件冲突时，请在主窗口更换组合。

这是未经代码签名的自编译应用，Windows 可能显示来源提示。
企业电脑若禁止运行未知应用，请联系管理员。
